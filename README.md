# Console Banking

Учебный консольный банковский проект на Java с использованием Spring Framework.  
Приложение имитирует базовые операции: создание пользователей, открытие и закрытие счетов, пополнение, снятие и переводы. Все данные хранятся в памяти и не сохраняются между запусками.

## Возможности

- создание пользователя по логину;
- просмотр списка пользователей;
- открытие счёта для пользователя;
- закрытие счёта;
- пополнение счёта;
- снятие средств;
- перевод между счетами;
- завершение работы приложения.

### Ограничения

- логин пользователя должен быть уникальным и непустым;
- при создании счёта на него зачисляется стартовый баланс;
- нельзя закрыть последний счёт пользователя;
- при закрытии счёта остаток переводится на другой счёт того же пользователя;
- при переводе между счетами разных пользователей взимается комиссия;
- при переводе между своими счетами комиссия не взимается;
- суммы операций не могут быть отрицательными;
- при снятии и переводе проверяется достаточность средств.

## Технологии

- Java 25;
- Spring Framework 7.0.10;
- Jakarta Annotation 3.0.0;
- JUnit 4.11;
- Maven.

В проекте используются Spring DI, паттерн «Команда», in-memory репозитории и кастомные исключения.

## Запуск

Требования:

- JDK 25 или совместимая версия, указанная в `pom.xml`;
- Maven 3.8+.
